# House on the Hill

A bilingual (English / Russian) web reader for the haunt books of
**Betrayal at House on the Hill, 3rd Edition**: the Traitor's Tome and Secrets of Survival.

Live site: https://chepash.github.io/house-on-the-hill/

## Development

Requires Node 24 LTS (Astro 7 needs Node 22.23 or newer).

```sh
npm install
npm run dev       # http://localhost:4321/house-on-the-hill/
npm run build     # static site in dist/
npm run preview   # serve dist/ locally
npm run check     # type-check .astro and .ts files
npm run sync      # copy notes and icons from the Obsidian vault (path: argument or VAULT_DIR)
```

`src/content/` and `public/icons/` are generated by `npm run sync` and committed.

Pushing to `main` builds and deploys the site with GitHub Actions.
