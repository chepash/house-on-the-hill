# Project rules

- Everything in the repository is in English: code, comments, commit messages,
  docs, the dev log. Russian is allowed only in `src/content/**/ru/` and in the
  Russian UI translation strings.
- After each iteration add an entry to `docs/DEVLOG.md` (newest first): what was
  done, decisions, next steps. Keep `docs/PLAN.md` in sync when the plan changes.
- Internal links must respect the GitHub Pages base path (`/house-on-the-hill`).
  Never hard-code root-relative URLs.
- Before finishing a change, run `npm run check` and `npm run build`.
- Astro-specific notes (dev server, docs links) are in `AGENTS.md`.

## Content

- `src/content/` and `public/icons/` are generated by `npm run sync` from the Obsidian
  vault. Do not edit them by hand: fix the vault note and sync again.
- The sync must finish without structure warnings: every note exists in `en/` and `ru/`
  with the same sequence of headings and callouts (the language switch depends on it).
- Never link from one book's haunt to the other book's haunt (spoilers).
- After changing `src/markdown/remark-obsidian.mjs`, delete `node_modules/.astro` and
  `.astro`: Astro caches rendered collection entries.
